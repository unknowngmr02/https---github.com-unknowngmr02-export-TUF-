From a lighthouse, two ships on the same straight line have angles of depression 30° and 60°. If the ships are 120 m apart, find the lighthouse height.
Q
Lighthouse sees two ships, depression 30° and 60°, ships 120 m apart. Find the height.
Given
∠ depression (near ship) = 60°
∠ depression (far ship) = 30°
Ships apart = 120 m. Find: h
Step 1
Let nearer ship distance = x
Let farther ship distance = y
Ships 120 m apart:
y − x = 120
Step 2
Need tan θ - it links height and base directly
Nearer ship (θ = 60°):
tan 60° = hx
√31 = hx
x = h√3
Step 3
Same idea for the farther ship (θ = 30°):
tan 30° = hy
1√3 = hy
y = h·√3
Step 4
We know y − x = 120
h·√3 − h√3 = 120
h · ( √3 − 1√3 ) = 120
h · 2√3 = 120
2h = 120√3 so
h = 60√3 m
G
