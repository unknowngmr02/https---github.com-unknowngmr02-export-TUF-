An acute angle has opposite side 8 and hypotenuse 17. What is its tangent?
Q
tanθ = oppositeadjacent
Opposite = 8, Hypotenuse = 17. Find tanθ.
Given
Opposite = 8
Hypotenuse = 17
Adjacent = X
Step 1
Using Pythagoras theorem:
hyp2 = opp2 + adj2
172 = 82 + X2
289 = 64 + X2
X2 = 289 - 64
X2 = 225
X = 15
Step 2
tanθ = opposite / adjacent
tanθ = 815
